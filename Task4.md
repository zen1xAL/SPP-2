# Лабораторная работа №4

## Постановка задачи
Разработать многопользовательскую веб-игру в режиме реального времени.

### Основные требования:
1. **Мгновенная синхронизация через WebSockets**:
   - Обеспечить синхронизацию действий всех участников игры в реальном времени с минимальной задержкой.
2. **Только чистый JavaScript (No Frameworks)**:
   - Клиентская часть приложения реализуется исключительно на чистом JavaScript (Vanilla JS / TypeScript с компиляцией в ES Modules), без использования сторонних UI-фреймворков (React, Vue, Angular и др.).
3. **Персистентность данных**:
   - Обеспечить сохранение состояния игры между перезапусками приложения (серверная база данных / журнал состояний).

### Дополнительные требования (на оценку 8 – 10):
1. **Конкурентный доступ и разрешение конфликтов**:
   - Предусмотреть сценарий одновременного редактирования/изменения одного и того же игрового элемента несколькими пользователями с детерминированным алгоритмом разрешения конфликтов (Last-Write-Wins, версионирование, распределенная блокировка).
2. **Устойчивость к потере соединения (Offline & Reconnect)**:
   - При разрыве интернет-соединения приложение должно сохранить текущее локальное состояние игрока (буферизация действий в LocalStorage / памяти) и корректно синхронизировать его после восстановления соединения.
3. **Развертывание на хостинге**:
   - Развернуть готовое веб-приложение на общедоступном хостинге (Render / Railway / Fly.io / VPS) и предоставить рабочую ссылку для проверки.
