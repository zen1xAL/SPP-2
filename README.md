## 📌 [Лабораторная работа №3](file:///d:/SPP/7sem/SPP/lab3/)

Расширение веб-приложения TaskFlow корпоративными стандартами безопасности, ролевой моделью доступа, контролем подключений и автоматизированным CI-пайплайном:
* Задание: [Task3.md](file:///d:/SPP/7sem/SPP/Task3.md).
* Ключевые возможности:
  1. **Ролевая модель доступа (RBAC)** с 3 ролями (`admin`, `manager`, `viewer`) на основе временных ключей (JWT Bearer Token с TTL 15 минут).
  2. **Семантика стандартов HTTP**: строгое соблюдение RFC 7231 / RFC 9110 (200, 201, 204, 400, 401, 403, 404, 409, 422, 429, 500) и единый JSON-формат ошибок.
  3. **Защита от подбора паролей**: Brute-Force Rate Limiting (HTTP 429 Too Many Requests с заголовком `Retry-After: 900`).
  4. **Контроль активных подключений**: просмотр списка активных сессий и возможность удаленного отзыва сессий (`204 No Content`).
  5. **Восстановление доступа через Email**: генерация криптографических одноразовых токенов сброса пароля.
  6. **Структурированное логирование**: легковесный JSON-логгер со сквозным Correlation ID (`X-Request-Id`).
  7. **Автоматизированная проверка кода (CI)**: GitHub Actions workflow (`.github/workflows/ci.yml`).

### Быстрый запуск в Docker Compose:

```bash
cd lab3
docker compose up --build
```

Приложение доступно по адресу: `http://localhost:3000`.

### Учетные записи для быстрой проверки ролей (Seed Data):
* **Администратор (admin)**: `admin@taskflow.local` / `AdminPass123!`
* **Менеджер (manager)**: `manager@taskflow.local` / `ManagerPass123!`
* **Наблюдатель (viewer)**: `viewer@taskflow.local` / `ViewerPass123!`

## 📌 [Лабораторная работа №4](file:///d:/SPP/7sem/SPP/lab4/)

Многопользовательская веб-игра в режиме реального времени **«CyberTanks: Neon Siege»**:
* Задание: [Task4.md](file:///d:/SPP/7sem/SPP/Task4.md).
* Ключевые возможности:
  1. **Мгновенная синхронизация через WebSockets**: авторитетный сервер на Node.js с игровым циклом 30 тиков/сек.
  2. **100% чистый JavaScript (No Frameworks)**: клиентская часть реализована на HTML5 Canvas 2D + ES Modules без React/Vue/Angular.
  3. **Сохранение данных игры**: персистентная база данных (PostgreSQL / SQLite) с сохранением профилей, побед, фрагов, разрушенных стен и таблицы лидеров.
  4. **Разрешение конфликтов конкурентного доступа (8–10 баллов)**: детерминированный арбитраж при одновременном подборе бонусов двумя танками и одновременном выстреле в кирпичную стену.
  5. **Устойчивость к потере связи (8–10 баллов)**: буферизация действий в `localStorage`, автореконнект с экспоненциальным откатом и бесшовное восстановление сессии по токену.
  6. **Сенсорное мобильное управление**: виртуальный D-Pad (джойстик) слева + кнопка «ОГОНЬ» справа с тактильным виброоткликом и адаптивным масштабированием под экраны смартфонов.
  7. **Развертывание на хостинге (8–10 баллов)**: готовый Docker-образ и конфигурация `render.yaml` для 1-клик деплоя на облачный хостинг Render / Railway.

### Быстрый запуск Лабораторной работы №4:

```bash
# Локальный запуск (Node.js)
cd lab4
npm install
npm run dev

# Либо запуск в Docker Compose (с PostgreSQL)
cd lab4
docker compose up --build
```

Приложение доступно по адресу: `http://localhost:3000`.
