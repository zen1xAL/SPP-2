# Лабораторная работа №1 – Веб-приложение для управления задачами

Веб-приложение с серверным рендерингом (Node.js, Express, EJS, TypeScript) для управления задачами со статусами, дедлайнами и вложениями файлов.

## Установка и запуск

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

## Сборка и тесты

```bash
npm test
npm run build
npm start
```
