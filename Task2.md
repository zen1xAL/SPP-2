Разработать приложение с архитектурой Single Page Application (SPA) на
клиенте и REST API на сервере, реализующее полный цикл CRUDопераций над данными. Обмен данными должен осуществляться путем
отправки/принятия http запросов в формате JSON и файлов в формате
multipart/form-data. Обновление данных на клиенте не должно приводить к
перегрузке страницы. Серверный REST API должен правильно
использовать http методы (GET для чтения данных, POST/PUT для
изменения, DELETE для удаления и т.п.) и возвращать правильные коды
ответов (200 в случае успешного чтения/изменения данных, 404 если ресурс
не найден и т.п.). На сервере необходимо предусмотреть проверку всех
входящих данных. Клиентский интерфейс должен информативно выводить
сообщения об ошибках. Обязательно использование NodeJS на сервере с
подключением базы данных. На клиенте можно использовать
React/Angular/Vue, можно без библиотеки. Весь проект должен быть
упакован и развернут в контейнерах Docker.
